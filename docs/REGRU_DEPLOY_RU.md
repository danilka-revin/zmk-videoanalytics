# Выкладка Zovod на reg.ru (VPS, домен maisaak-3dprintlab.online)

Вся конфигурация деплоя уже вшита в проект:

| Что | Где |
|---|---|
| Пароли панели (`admin` и `director` = `72327232`) | `deploy.env` → применяется автоматически при каждом `./start.sh` |
| Домен, CORS, Telegram Mini App | `deploy.env` |
| HTTPS (сертификат Let's Encrypt, порты 80/443) | сервис `caddy` в `docker-compose.yml` + `services/https/Caddyfile` |
| Сброс паролей ВСЕХ пользователей одной командой | `bash set-passwords.sh` |
| Одноразовая доводка сервера (файрвол и т.п.) | `bash setup-regru.sh` |

---

## Что нужно сделать (короткий путь)

### 1. DNS — в панели reg.ru (делается один раз, не на сервере)

**«Мои домены» → maisaak-3dprintlab.online → Управление DNS-записями:**

| Тип | Имя | Значение | TTL |
|---|---|---|---|
| `A` | `@` | IP-адрес вашего VPS | 3600 |
| `A` | `www` | IP-адрес вашего VPS | 3600 |

Обновление DNS — от минуты до суток (обычно до часа). Проверка:
`ping www.maisaak-3dprintlab.online` должен показывать IP сервера.

### 2. Запуск на сервере

```bash
ssh root@<IP-VPS>
cd /opt/zmk-videoanalytics   # папка с проектом
./start.sh --no-open
```

Первый запуск: мастер спросит про ботов (можно «без бота»), затем идёт сборка
образов 5–20 минут. Каждый запуск автоматически применяет `deploy.env`
(пароли, домен) к `.env`.

### 3. Одноразовая доводка сервера

```bash
bash setup-regru.sh
```

Скрипт отключит nginx/apache (если мешают), откроет файрвол
(22, 80, 443, 8555 TCP+UDP), поставит пароль `72327232` всем пользователям
и проверит ответ сайта по домену. **Также откройте порты 80, 443 и 8555
(TCP+UDP) в файрволе панели reg.ru**, если он там настроен.

### 4. Готово

- Сайт: **https://www.maisaak-3dprintlab.online** (и https://maisaak-3dprintlab.online)
- Вход: **admin** / **72327232** (полный доступ), **director** / **72327232** (просмотр)
- Живое видео камер: порт **8555** (TCP+UDP) должен быть открыт

HTTPS выпускается и продлевается автоматически (Caddy + Let's Encrypt).
Если сертификат ещё не выпустился — `docker compose restart caddy`.

## Полезные команды

```bash
./start.sh --no-open          # обычный запуск (и после обновлений)
docker compose ps             # состояние сервисов
docker compose logs -f api    # логи API
bash set-passwords.sh         # пароль 72327232 ВСЕМ пользователям
bash set-passwords.sh НОВЫЙ   # свой пароль ВСЕМ пользователям
bash setup-regru.sh           # файрвол + проверка домена
```

## Как менять конфигурацию

Правьте **`deploy.env`** (он в git и применяется при каждом запуске):
пароли, домен, CORS, Telegram-адрес. Не трогайте `.env` — его значения,
относящиеся к deploy, будут перезаписаны при следующем запуске.

## Обновление

Обычное: кнопка **«Обновление»** в панели или `./start.sh` (сам подтянет
новую версию). Конфигурация деплоя применится автоматически.

## Важно про камеры (RTSP)

Zovod тянет RTSP-потоки с камер. Если камеры в локальной сети предприятия,
а VPS — в облаке, сервер не увидит `192.168.x.x` напрямую. Варианты:

- **VPN (рекомендуется):** WireGuard между площадкой и VPS;
- проброс RTSP-портов на роутере площадки (менее безопасно);
- запуск Zovod внутри сети предприятия (on-premise — основной сценарий).

Камеры добавляются в разделе **Камеры**: RTSP-URL вида
`rtsp://логин:пароль@адрес:554/стрим`.

## Если что-то не работает

| Симптом | Решение |
|---|---|
| Домен не открывается | `ping www.maisaak-3dprintlab.online` — если IP не тот, ждите DNS; потом `docker compose restart caddy` |
| Ошибка сертификата | Порты 80/443 должны быть открыты наружу; `docker compose logs caddy` |
| Не пускает в панель | `bash set-passwords.sh` — сбросит пароль у всех на `72327232` |
| Сборка зависла на `npm ci` | В `.env` добавьте `NPM_REGISTRY=https://registry.npmmirror.com`, затем `./start.sh --rebuild` |
| Сервис в `docker compose ps` в состоянии Exit | `docker compose logs --tail=50 имя-сервиса` |
