# Автодообучение на кадрах камеры

Панель создаёт задачу fine-tuning: захват кадров выбранной online-камеры → проверка качества → псевдоразметка активной моделью → разбиение train/val → обучение → валидация → экспорт ONNX → регистрация модели. Новая модель **не активируется автоматически**: оператор проверяет метрики и выполняет атомарный hot-swap.

В демо worker воспроизводит полный жизненный цикл и регистрирует артефакт без тяжёлого GPU-обучения. Для production реализация `run_training` заменяется на изолированный GPU worker (Ultralytics/TensorRT), а изображения и разметка сохраняются в MinIO. Псевдоразметка должна проходить ручную верификацию: обучение на одном неразмеченном кадре не обеспечивает корректную модель.

Защита: offline-камера отклоняется, активная модель не меняется при ошибке, параметры ограничены Pydantic, все переключения пишутся в audit log.
