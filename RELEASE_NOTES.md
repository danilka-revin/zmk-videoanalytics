# ZMK Vision v2.9.0 — Ready-made model catalog with one-click download

## Новая возможность: готовые нейронки в один клик

Прямо из формы **«Зарегистрировать модель»** теперь есть блок **«Готовые модели — скачать в один клик»**: предобученные веса YOLO, скачиваются и регистрируются в реестре одной кнопкой — не нужно ничего указывать вручную.

### Что реализовано

- **Каталог готовых моделей** (`GET /api/models/presets`): `yolo11n` (5.4 МБ), `yolov8n` (6.5 МБ), `yolo11s` (19 МБ) — рекуррентные (реальные, проверенные) общедоступные веса ultralytics. Показывается формат, число классов, размер, категория и статус (скачана ли).
- **Одноклик-скачивание** (`POST /api/models/presets/{id}/download`): скачивает файл в `MODEL_DIR` (том `model-data`), вычисляет SHA256, проверяет размер и регистрирует модель со статусом `ready`, `source=preset:<id>` и checksum.
  - Повторный запрос → `already:true` (идемпотентно), файл не перекачивается.
  - Неизвестный пресет → `404`; недопустимое имя → `422`.
- **Web-панель**: в форме регистрации секция готовых моделей с кнопкой «Скачать», размером, числом классов и честным предупреждением.
- **Расширяемый каталог**: env-переменная `ZMK_MODEL_PRESETS_JSON` (массив JSON) позволяет добавить свои URL — удобно для self-hosted источников.
- **Общий том**: API теперь монтирует `model-data:/models` (`MODEL_DIR=/models`), чтобы скачанные модели были доступны inference- и training-воркерам.

### Честность (важно)

Это **COCO-предобученные веса**. После скачивания метрики purposeful **не заданы** (`null`), поэтому:
- активация **откажет** (`409: Метрики модели ниже минимально допустимых`), пока вы не обучите на своих данных или не укажете метрики валидации;
- такие модели **не дадут события безопасности** (нет классов `no_helmet / no_vest / phone_usage / smoking / restricted_zone / immobility`), пока вы не обучите на соответствующих метках.

Они полезны как **отправная точка для дообучения** (fine-tune на своих фото/видео/датасете) и для **предпросмотра** базовой детекции. Это явно указано в интерфейсе и в `README`.

## Примечание

URL проверены и отвечают доступными файлами. Скачивание выполняется на сервере (backend), браузер не качает файл напрямую. Песочница проверяла локальный mirror, реальная публичная загрузка подтверждена smoke-тестом.
