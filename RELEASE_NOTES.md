# ZMK Vision v2.4.0 — Обновление из панели (Update button)

- В шапке Web-панели появились кнопки **проверить обновление** и **«Обновить до последней версии»**.
- Добавлен сервис `updater`: монтирует каталог проекта на хосте и Docker-сокет, поэтому обновление действительно применяется, а не имитируется.
- При клике на «Обновить» сервис скачивает последний релиз, сверяет контрольную сумму **SHA256**, проверяет члены архива от path traversal/ссылок, накладывает новые файлы на место (сохраняя `.env`, `./data`, базы данных и Compose-профили) и пересобирает стек.
- Новые API: `GET /api/update/status`, `POST /api/update/apply`; обновлённый `GET /api/capabilities` сообщает о подключённом сервисе обновления.
- Кнопка работает честно: если сервис `updater` не запущен — она сообщает, что обновление недоступно, а не выдаёт ложный успех.
- Показатель версии в сайдбаре теперь берётся из реального `/api/health`, а не зашит в код.
- Установщики генерируют `ZMK_UPDATE_TOKEN` для защиты эндпоинтов обновления.
- Добавлены юнит-тесты ядра обновления (скачивание → SHA256 → распаковка → подмена) на локальном mirror-сервере и тесты деградации API без updater.
