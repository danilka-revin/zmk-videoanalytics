# ZMK Vision v2.10.0 — Model delete, camera black-screen fix, settings help

## 1. Удаление модели с двойным подтверждением

- В карточке модели появилась кнопка **«Удалить»**.
- При нажатии — **два подтверждения** подряд (первое: «удалить модель?», второе: «вы уверены? Нельзя отменить»), чтобы случайный клик не стёр нейронку.
- Бэкенд `DELETE /api/models/{name}`:
  - **отказывается удалять активную модель** (`409`) — сначала надо переключиться на другую через «Горячая замена»;
  - отказывается удалять модель, занятую текущей задачей обучения (`409`);
  - удаляет запись из реестра **и файл с диска** (если это локально скачанная модель `source=preset:*`, и файл лежит в `model-data`);
  - пишет в журнал событие удаления.

## 2. Чёрный экран камеры / постоянный «офлайн» — исправлено

Симптом: камера отлично работает в VLC, но на сайте — чёрный экран и камера постоянно уходит в офлайн. Причина: ОpenCV по умолчанию открывает RTSP по **UDP** (пакеты теряются → чёрный кадр), а единичный сбой чтения сразу помечал камеру «офлайн».

Что сделано в inference-воркере:
- **RTSP теперь по TCP** (`OPENCV_FFMPEG_CAPTURE_OPTIONS=rtsp_transport;tcp`), переопределяется `RTSP_TRANSPORT`.
- Явный бэкенд `CAP_FFMPEG`, таймауты open/read, буфер 1 кадр (меньше задержка).
- **Порог «офлайн»**: камера считается офлайн только после `OFFLINE_AFTER_FRAMES` (по умолчанию 3) неудачных кадров подряд — единичный сбой больше не мигает статусом. Появляется промежуточный статус **«Восстановление»**.
- **Переподключение с бэкоффом**: потерянный поток переоткрывается (закрытие шедшей каптации) с интервалом `RTSP_RECONNECT_SECONDS` (по умолчанию 5 с), а не долбится каждый кадр.
- Снимки и телеметрия теперь не падают, если сеть чуть подвисла (worker живёт дальше).

## Примечание

Для реального исправления на вашей машине: примените обновление, перезапустите инференс-воркер (`docker compose --profile inference up -d --build`), и камера должна перейти в TCP-режим. Если всё равно чёрная — проверьте логи воркера (`docker compose --profile inference logs --tail=100 inference-worker`) и пришлите их: возможно, нужен конкретный кодек или параметры потока.
