# ZMK Vision v2.4.1 — Fix blank camera frames + full re-check

## Исправления картинки камеры

- Найдена и подтверждена причина «чёрной» карточки камеры: снимок не поступал из `inference-worker` (worker не запущен, не выбран профиль `inference`, или не открывается RTSP-поток), при этом интерфейс молча показывал тёмную рамку без объяснения.
- Проверен весь контур **кадр → snapshot → картинка** на уровне API:
  - `POST /api/cameras/{id}/snapshot` — загрузка снимка (валидация base64, JPEG-маркеры, размер) — подтверждено, работает;
  - `GET /api/cameras/{id}/snapshot` — отдача `image/jpeg` — подтверждено, работает;
  - Удаление камеры удаляет и файл снимка — подтверждено.

## Что добавлено, чтобы проблема была видна, а не молчала

- Каждая камера теперь отдаёт `snapshot_age_seconds` — возраст последнего кадра (или `null`, если кадра ещё нет).
- Диагностика (`/api/diagnostics`) различает состояния: `fresh` / `stale` / `none` и показывает возраст кадра для каждой камеры.
- Статус сервиса `inference` в диагностике теперь честно отражает фактическое поступление кадров, а не наличие зарегистрированной модели.
- Карточка камеры в панели при отсутствии кадра показывает причину: «Поток не подключён / RTSP недоступен» либо «Кадр не получен — нет свежего снимка от inference worker», а при наличии кадра — его возраст («только что», «N сек назад», «N мин назад»).
- `inference-worker` теперь логирует в `docker compose logs inference-worker` понятное сообщение, если камера не отдаёт кадр (проверьте RTSP URL, учётные данные и сеть).
