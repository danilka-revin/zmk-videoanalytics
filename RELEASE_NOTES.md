# ZMK Vision v2.7.0 — Training on a plain photo pack and a video pack

## Новое: три источника данных для обучения

Теперь модель можно обучить не только на кадрах с камеры или размеченном YOLO-датасете, но и на **простой папке фото** или **пачке видео**.

### 1. Папка фоток (без разметки)
Загрузите `.zip` с обычными фотографиями (`.jpg/.png/.webp/...`). Бэкенд сам определяет тип `images` (нет `data.yaml` и labels), а training worker **автоматически размечает** каждое фото активной моделью (или YOLO11n) и обучает на них.

### 2. Пачка видео
Загрузите `.zip` с видеофайлами (`.mp4/.avi/.mov/.mkv/...`). Бэкенд определяет тип `videos`; worker **нарезает кадры** из видео (с заданным шагом), авторазмечает их псевдоразметкой и обучает.

### 3. YOLO-датасет (как раньше)
Загрузка `data.yaml + images/ + labels/` — размеченный датасет, обучение без авторазметки.

Тип определяется автоматически при загрузке. Задача обучения получает `dataset_kind`, который передаётся в worker.

## Что добавлено

- `POST /api/datasets` — автоопределение типа: `yolo` / `images` / `videos`, валидация (минимум 10 фото либо 1 видео, защита от zip-бомб).
- `datasets` таблица: новые поля `kind`, `media_count`, `label_count`.
- `GET /api/datasets` отдаёт тип и количество медиа; для видео — число файлов, для фото — число изображений.
- Training worker: общий модуль псевдоразметки + `_extract_frames` (нарезка кадров из видео с шагом `frame_skip`), обучение по фото и по видео.
- Web-панель: подпись «Фото / Видео / YOLO-датасет» у загруженных датасетов и объяснение, какие типы принимаются.

## Примечание

Реальное обучение по-прежнему требует запущенного `training-worker` (Compose profile `training`, NVIDIA GPU желателен). Загрузка, автоопределение и валидация датасетов работают всегда. Авторазметка выполняется активной моделью или YOLO11n — качество меток зависит от базовой модели.
