# ZMK Vision v2.11.2 — RTSP URL handling in the edit form clarified

## Симптом

При нажатии «Изменить» у камеры в поле RTSP URL не отображается ссылка, которую вводил ранее.

## Причина (важно: ссылка НЕ потеряна)

RTSP URL — это **секрет** (содержит логин/пароль), поэтому API **никогда не возвращает его** обратно. Вместо него фронтенд получает только флаг `configured`. Это сделано намеренно — чтобы пароль камеры не светился на сайте и в коде панели.

При этом сама ссылка **сохраняется в базе**:
- в `UPDATE` используется `COALESCE(?, rtsp_url)` — если клиент прислал `null` (как и делает форма при пустом поле), старая ссылка остаётся.

То есть функционально всё работало правильно, просто поле выглядело пустым и вводило в заблуждение.

## Что сделано

### Бэкенд — надёжность
- `update_camera` теперь меняет RTSP URL **только если прислана непустая строка**. И `null`, и `""` («оставить как есть») сохраняют прежнюю ссылку.
- Ответ `PUT` возвращает `configured` (есть ли ссылка) и `rtsp_updated` (менялась ли она).

### Фронтенд — понятность
- В форме **«Изменить»** вместо пустого поля теперь сообщение: **«Ссылка уже настроена и скрыта»** + чекбокс **«Ввести новую ссылку»**.
- Только при включении чекбокса открывается поле для новой ссылки. Если его не включать — старая ссылка сохраняется (сейчас это неочевидно).
- Поле новой ссылки — типа `password` (как и было), пароль камеры не отображается.

## Проверки

- Backend **60/60** (добавлен тест: редактирование без новой ссылки сохраняет URL; исходная ссылка никогда не возвращается API), установщики/updater/worker **28/28**, Telegram 3/3, MAX 3/3.
- Ruff, Bandit (прод+updater), tsc/lint, `npm audit` (0), pip-audit (0), `git diff --check` — чисто.

## Как это выглядит теперь

При «Изменить»:
```
RTSP URL — Ссылка уже настроена и скрыта. Чтобы заменить её — включите «Ввести новую ссылку» ниже.
[ ] Ввести новую ссылку
```
Если включить чекбокс — появится поле `Новая RTSP URL` (пароль).

Проверить, что ссылка на месте, можно так:
- на карточке камеры бейдж `RTSP SET` ⇒ ссылка задана;
- диагностика камеры покажет «Доступна · N мс» ⇒ ссылка рабочая.

## Примечание

Если вам нужно ВИДЕТЬ саму ссылку (например, для проверки) — это сознательно недоступно через сайт ради безопасности секрета. Ссылка хранится только в `.env`-записи камеры и в базе данных проекта; увидеть её можно через прямой доступ к БД (`docker compose exec api ...`), но не через панель.
